# VIVI Music (iOS / Swift)

[VIVI Music](https://github.com/vivizzz007/vivi-music) の iOS / iPadOS 版。
YouTube Music のホーム・探索・検索・ライブラリ・同期歌詞・オフライン保存・イコライザー / 音響効果に対応した SwiftUI 製クライアント。

- 対象: iOS / iPadOS 17.0 以上 (iPhone / iPad)
- ビルド: GitHub Actions + XcodeGen (Mac 不要)。push すると無署名 IPA が成果物に出る
- 配布: SideStore でサイドロード
- 診断ログ: 設定 → 診断ログ から閲覧・共有できる

画面構成・診断ログ・ビルド手順・現状の制約は [docs/Overview.md](docs/Overview.md) を参照。
